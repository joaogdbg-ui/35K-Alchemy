# V30 semantic icon standards

1. **Semantic accuracy before numerical uniqueness.** A Sun must read as a sun, not a lightning/star glyph. Sky must look like sky; Wind must look like airflow; Crystal must be a crystal, not a potion.
2. **Visual distinctiveness where it matters.** Newly introduced games in V30 have different original thematic SVG compositions, drawing on varied subjects and small secondary motifs rather than only palette substitutions.
3. **Highest-priority exact-name asset selection.** Use the canonical English name, exact match. Avoid broad substring rules affecting unrelated names such as *Skyward Sword* or *Pokémon Crystal*.
4. **Original game assets only.** Avoid reproducing official logos, box covers or protected key art. References to games are informational; themes may be suggested with original objects and motifs.
5. **Offline static performance.** No animation frames, AI calls, image decoding on every combination or per-frame drawing. Assets are embedded once and the inventory remains virtualized.
6. **Quality gate for future items.** Every new item needs a visual review; key games and characters need an explicitly authored semantic art assignment. If a generic family is reused, it should visibly represent the name or class. Reject nonsensical mappings.
7. **Progress never depends on artwork ID.** Changing a drawing must not renumber items, alter recipe keys or reset player discoveries.

**Current coverage:** 104 exact-name V30 artworks plus older illustrations and shared motifs; remaining legacy art audit is in progress, not finished.
