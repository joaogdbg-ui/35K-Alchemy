# V32 — Discovery Compass and organic content

**Reasoning:** Forced trial-and-error becomes frustrating in very large catalogs. An optional first-ingredient suggestion should support reasoning without spoiling a result. Players can request a full pair using the already-established offline credit economy, but only actual crafting unlocks the element.

**Algorithm:** Build eligible pairs from the deterministic recipe map for outputs not yet unlocked, requiring both ingredients to be in the player's collection. Prioritize the left locked ingredient, reachable shallow paths, gaming categories and under-explored families. The suggestion list rotates to prevent repeated advice. This list is computed only on request, not every animation frame.

**Quality:** 26 curated elements with 48 unique unordered recipes; no pre-existing pair overwritten; all elements reachable from the four starting elements. All new results have an English name, concise factual description, original static semantically matched SVG icon and optional humorous one-line reveal copy. No fictional statistics.

**Scope deliberately excluded:** Replacing the crafting slots with a freeform canvas; converting the game into a hosted AI service; reworking ad monetization or adding a large modal to the main Play screen.
