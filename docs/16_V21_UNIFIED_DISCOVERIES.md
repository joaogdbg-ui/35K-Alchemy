# Gameverse V21: unified Discoveries & inline recipes

- Navigation has **two tabs only**: Play and Discoveries. Removed visible Collection and Recipe Book.
- Discoveries contains the 9 families, collection counts, search, Found/???? filters, free hints and optional future rewarded ads.
- Every found element row has a static cartoon icon, the name and an inline recipe (e.g. Camera, with ingredient names directly below).
- If alternative recipe paths have actually been discovered, a button displays those paths; the initial recipe is recovered from legacy progress or the canonical catalog when history is unavailable.
- Starter elements show **Starting element**. Locked items show **????**, with their recipe hidden unless the player has bought a clue.
- Tapping a found row returns to Play and immediately inserts the item into the craft slot: no intermediate selection modal.
- Retains all 2,788 elements and 5,078 offline recipes from V20. No online features or ad SDK activated.
- Saves stay compatible with all previous Gameverse versions; no IDs or storage keys changed.
