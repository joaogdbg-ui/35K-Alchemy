# Norma de qualidade visual — 35K Alchemy

1. Cada item deve ter uma silhueta específica e reconhecível sem precisar de ler o nome.
2. Testar SVG a aproximadamente **35px**, em temas claro e escuro.
3. Evitar o antigo sistema de recombinar motivos genéricos para muitos elementos (por exemplo, flor+câmara).
4. Variar anatomia, mecanismos, geometrias, materiais, texturas, perspetivas e composição, mantendo o estilo cartoon/pastel original.
5. SVG diferente por hash não prova arte distinta. Auditor pHash e duplicados são filtros; **revisão humana é indispensável**.
6. Referências de jogos semelhantes podem inspirar princípios gerais de legibilidade, nunca copiar imagens, logótipos, sprites ou personagens de terceiros.
7. A meta de cerca de 200 novos elementos por versão **não é obrigatória**. Reduzir o lote quando não houver desenhos ou receitas suficientemente bons.
8. Pendência V67: **100 redesenhos** específicos da V61; fazer follow-up com inventário e testes para impedir regressões.
